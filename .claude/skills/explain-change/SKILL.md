# Explain a change

Inspect the requested diff and relevant callers. Describe the previous behavior, the resulting behavior, and the reason for the change. Include a concrete example when it clarifies the difference.

Distinguish checks you ran from checks reported by someone else. Mention unresolved questions that affect the conclusion. Link to the relevant files and keep the explanation proportional to the change.

This is an explanation workflow. Do not modify files or publish comments unless the user requests those actions.
